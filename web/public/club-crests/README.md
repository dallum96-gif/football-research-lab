# Matchday club crests

Original SVG artwork downloaded from the Premier League asset server on 2026-09-09, covering all 20 clubs in FRL's verified 2026-27 identity registry. Each file is named with its verified persistent team code, not a season-local team ID.

`web/src/data/club-crests.json` records the exact source URL, SHA-256, retrieval date and explicit canonical registry name variants for each asset. Artwork is preserved without recolouring, cropping or AI recreation. The component uses aspect-preserving display boxes and falls back to the existing TeamKit for unknown clubs or failed image loads.

These are current identity illustrations, not evidence of which crest a club used at a historical fixture date. Historical clubs without an asset retain TeamKit. The assets are served locally; rendering does not call the upstream server.

Rights remain with the respective rights holders. Public availability does not establish a redistribution or commercial-use licence. Rights status remains REVIEW REQUIRED under FRL_SOURCE_RIGHTS_REGISTER.md; local integration does not constitute public-release approval.
